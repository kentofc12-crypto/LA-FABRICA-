## 3. PR戦略（認知爆発のための5つの柱）

### 柱1：プレスリリース × メディア露出
```
配信先: PR TIMES / @Press / ValuePress
ターゲットメディア:
  - サカイク（日本最大の育成メディア）
  - ジュニアサッカーNews
  - フットボールチャンネル
  - Yahoo!スポーツ
  - 地方スポーツ紙

タイミング:
  - 5月: 「日本初のプレーコンサルタント、育成革命を宣言」
  - 9月: 「IDP正式ローンチ、パイロット参加者の成長率○%向上」
  - 12月: 「年内○○人分析完了、データから見えた日本の育成課題」
```

### 柱2：インフルエンサー・コーチ連携
```
対象:
  - サッカー系YouTube（登録者5万〜50万）との対談
  - 現役・元Jリーガーとのコラボ
  - 育成コーチ・指導者コミュニティへのアプローチ

目的:
  - 「プレーコンサルティング」という言葉を広める
  - 信頼性の担保（第三者の推薦）
```

### 柱3：セレクション連動キャンペーン
```
日程:
  - 3〜5月: 関東・関西Jアカデミーセレクション
  - 7〜8月: 夏セレクション・クラブ移籍期
  - 10〜11月: 冬のセレクション・高校受験
  - 12月: 年明けセレクション準備

施策:
  「セレクション○日前からの緊急IDP分析」
  「セレクション落ちた選手のための原因分析」
  ← 検索タイミングに合わせて記事・動画を投下
```

### 柱4：法人（クラブ・スクール）開拓
```
ターゲット:
  - 民間サッカースクール（全国1,000校以上）
  - Jリーグ下部アカデミー
  - 高校サッカー部（強豪校顧問）
  - 個人コーチ・フリーランストレーナー

提案内容:
  - 「チーム顧問プラン」月額制
  - 「スクール生全員IDP分析パック」団体割引
  - 「コーチ向けプレーコンサルティング研修」
```

### 柱5：研究所レター→LINE公式への誘導
```
登録ステップ:
  YouTube視聴 → 研究所レター登録 → LINE公式友達追加 → 無料相談 → IDP

LINEで送るコンテンツ:
  Day0: 「プレーコンサルティングとは何か」
  Day3: 「自分の強みを知る3つの質問」
  Day7: 「日本のトップ選手が個人分析で気づいたこと」
  Day14: IDP無料相談の案内
  Day30: 期間限定特別オファー
```
