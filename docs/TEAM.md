## COO（コンテンツ統括）

### 役割

```
・YouTube部署・メディア部署・リサーチ部署の横断管理
・コンテンツ品質の最終責任者
・IDP/IDCサービスとのすり合わせ（酒本と週次）
・KPI管理・数値レビュー（週次）
・365日稼働スケジュールの維持
```

### KPI責任

| 指標 | 目標（6ヶ月） |
|-----|-------------|
| YouTube月間視聴回数 | 30,000回 |
| メディア月間セッション | 15,000 |
| 研究所レター登録者数 | 1,000人 |
| IDP/IDC月間問い合わせ | 25件 |

## 部署1: YouTube コンテンツ部署

### 組織図

```
┌────────────────────────────────────────────────┐
│           YouTube コンテンツ部署               │
│                                                │
│  Project Leader（企画・進行管理）              │
│        │                                      │
│   ┌────┴──────────────┬──────────────┐        │
│   │                   │              │        │
│  企画チーム        台本チーム      編集チーム  │
│  (2名)            (2名)           (2名)       │
└────────────────────────────────────────────────┘
```

### Project Leader

```
役割:
・YouTube部署全体の進行管理
・週間・月間コンテンツカレンダーの管理
・酒本（出演者）とのスケジュール調整
・COOへの週次報告
・各チームの締め切り管理

1日の動き:
 9:00  昨日の数値確認（視聴回数・CTR・登録者数）
10:00  各チームの進捗確認
12:00  COOへの報告・相談
15:00  翌週コンテンツの確認・フィードバック
17:00  酒本へのブリーフィング（翌日撮影がある場合）
```

### 企画チーム（2名）

```
メンバー:
・企画リーダー（国内リサーチ担当）
・企画メンバー（国外リサーチ担当）

役割:
・ネタ探し（国内・国外・365日）
・トレンドサッカーニュースの収集
・視聴者コメント・需要分析
・動画タイトル案の生成（週10案以上）
・企画書の作成（週4本分）

1日の動き（企画リーダー）:
 8:00  国内サッカーニュースチェック（Jリーグ・日本代表等）
 9:00  YouTube競合チャンネルのトレンド分析
10:00  企画書作成（台本チームへの引き渡し用）
13:00  国際ニュースレビュー（企画メンバーと共有）
15:00  タイトル候補10案を Project Leader に提出
17:00  翌日ネタのピックアップ

1日の動き（企画メンバー・国外担当）:
 8:00  海外サッカーメディアチェック（The Athletic, Marca, L'Equipe等）
 9:00  海外育成メソッド・科学論文のチェック
11:00  国外ネタの日本語サマリー作成 → 企画リーダーに共有
14:00  YouTube海外チャンネル（育成・戦術系）のトレンド確認
16:00  「日本で語られていないが海外では常識」ネタのリスト更新
```

**ネタ収集ソース（企画チーム管理）**

| カテゴリ | 国内ソース | 国外ソース |
|---------|-----------|-----------|
| 試合・戦術 | Jリーグ公式・Goal Japan | UEFA/FIFA・The Athletic・Marca |
| 育成・科学 | JFA育成情報・スポーツ科学誌 | Ajax Method・Barça Academy・科学論文 |
| 選手情報 | 国内移籍・育成年代大会結果 | Transfermarkt・海外ユース情報 |
| トレンド | Twitterサッカー界隈 | Reddit r/soccer・海外YouTube |
| 競合チャンネル | 国内サッカーYouTube上位 | 海外育成チャンネル上位 |

### 台本チーム（2名）

```
メンバー:
・台本リーダー（メイン台本担当）
・台本メンバー（Shorts・サポート担当）

役割:
・企画書を受け取り、酒本先生スタイルの台本に仕上げる
・フック・結論先出し・CTA の設計
・Shorts用の60秒台本作成（長尺から切り出し）
・酒本への事前ブリーフィング資料作成

台本制作フロー:
 企画書受取 → リサーチ追加 → 構成作成 → 台本初稿
   → Project Leaderレビュー → 酒本確認 → 完成

制作ガイドライン（酒本先生スタイル）:
 ① フック（0:00〜0:30）: 視聴者の痛みを代弁
 ② 結論先出し（0:30〜1:00）: 今日言いたいことを先に
 ③ 根拠・信頼性（1:00〜2:00）: IDP分析・データで裏付け
 ④ 詳細解説（2:00〜11:00）: 3ポイント構成
 ⑤ まとめ（11:00〜12:00）: 一言で言い切る
 ⑥ CTA（12:00〜13:00）: 研究所レター → IDP → IDC

週間スケジュール:
 月: 企画書受取・リサーチ追加
 火: 台本初稿作成
 水: Project Leaderレビュー
 木: 修正・酒本確認
 金: 完成・撮影準備
 土: Shorts台本作成（翌週分）
 日: 予備・改善
```

### 編集チーム（2名）

```
メンバー:
・編集リーダー（長尺動画担当）
・編集メンバー（Shorts・サムネイル担当）

役割:
・撮影素材の編集（長尺：10〜15分）
・テロップ挿入（スガワラくん型・全セリフにテロップ）
・BGM・効果音の設定
・サムネイル制作
・Shorts編集（週2〜3本）
・YouTube アップロード・設定（タイトル・概要欄・タグ）

使用ツール:
・編集: Premiere Pro / DaVinci Resolve
・テロップ自動生成: CapCut / Descript（精度確認後修正）
・サムネイル: Photoshop / Canva Pro
・Shorts: CapCut（縦型最適化）

1本あたりの制作時間目安:
 長尺（10〜15分）: 撮影1時間 → 編集6〜8時間
 Shorts（60秒）: 素材切り出し30分 → 編集1時間

週間スケジュール:
 月: 先週撮影素材の編集開始
 火〜水: テロップ・BGM・修正
 木: Project Leader確認・修正
 金: 公開（長尺1本）
 土〜日: Shorts編集（2〜3本・月〜水公開分）
```

### Marketing Leader

```
役割:
・メディア全体の戦略管理
・コンテンツ → 研究所レター登録 → IDP/IDC購買の数値管理
・SEOキーワード優先順位の決定
・研究所レター（メルマガ）の戦略設計
・YouTube部署との連携（コンテンツの橋渡し）
・COOへの週次報告

重点KPI:
 ・研究所レター登録転換率（記事→登録）
 ・メルマガからのIDP/IDC問い合わせ数
 ・検索流入比率
```

### 編集チーム（3名）

```
メンバー:
・編集長（品質管理・最終確認）
・ライター1（戦術分析・エビデンス記事担当）
・ライター2（育成・選手向け・保護者向け記事担当）

役割と分担:
 編集長:
  ・全記事の最終校正・品質確認
  ・記事スタイルガイドの管理
  ・月間編集カレンダーの管理
  ・ライターへのフィードバック

 ライター1（戦術・エビデンス担当）:
  ・週2本: 戦術分析・エビデンス記事
  ・プロ試合・選手の分析記事（権威性構築）
  ・海外論文・データの記事化
  → リサーチ部署の国外チームと連携

 ライター2（育成・購買層担当）:
  ・週2本: 選手向け・保護者向け記事
  ・「伸び悩み」「セレクション」「メンタル」テーマ
  ・成長ストーリー記事（IDC参加者取材）
  → IDP/IDCとの連携でネタ収集

記事制作フロー:
 リサーチ部署からネタ受取
   → キーワード確認（SEOチームと）
   → 構成作成
   → 初稿執筆
   → 編集長レビュー
   → CTAボックス挿入（誘導チームが設定）
   → 公開

週間スケジュール（ライター）:
 月: テーマ・キーワード確認、リサーチ
 火: 構成・初稿
 水: 編集長フィードバック
 木: 修正・完成
 金: 公開（週2本 = 月・木 or 火・金）
```

### SEO/配信チーム（1名）

```
役割:
・SEOキーワードリサーチ（月次）
・各記事のメタ情報設定（タイトルタグ・ディスクリプション）
・検索順位モニタリング（週次）
・SNS配信（Twitter/X・Instagram）
・研究所レターの配信管理（週1回）
・YouTube・メディア間の内部リンク管理

使用ツール:
・SEO: Ahrefs / Ubersuggest / Google Search Console
・SNS: Buffer / Hootsuite（予約投稿）
・メルマガ: Mailchimp / Substack / ConvertKit
```

### 誘導チーム（1名）

```
役割:
・記事末CTAボックスのコピー・デザイン管理
・研究所レター登録フォームの最適化
・ステップメール（Day 0〜30）の管理・改善
・A/Bテスト（タイトル・CTA文言）
・IDP/IDCへの問い合わせ数を最大化
・コンバージョン率の週次レポート

重点管理指標:
 ・記事→レター登録率（目標 3%以上）
 ・レター→IDP相談転換率（目標 5%以上）
 ・IDP相談→IDC申込率（目標 30%以上）
```

## 365日稼働スケジュール

### 週間サイクル

```
月曜
 ├── リサーチ部署: 週間ネタリスト提出
 ├── YouTube企画チーム: ネタ受取・企画書作成開始
 ├── メディア編集チーム: 記事1本公開
 └── 全体: 先週数値レビュー（COO主催 30分）

火曜
 ├── YouTube台本チーム: 台本初稿提出
 ├── メディアライター: 記事初稿提出
 └── SEOチーム: SNS配信（月曜記事のSNS拡散）

水曜
 ├── YouTube: Project Leader台本レビュー
 ├── メディア編集長: 記事レビュー・フィードバック
 └── Shortsチーム: 今週Shorts 1本公開

木曜
 ├── YouTube: 酒本台本確認・撮影準備
 ├── メディア: 記事修正・完成
 └── 誘導チーム: CTA設定・公開

金曜
 ├── YouTube: 長尺動画 1本公開（週のメイン）
 ├── メディア編集チーム: 記事2本目公開
 └── 研究所レター: 週次配信（金曜18時）

土曜
 ├── YouTube Shorts: 2本公開
 ├── メディアSNS: 週末配信（エンゲージメント高い時間帯）
 └── 編集チーム: 翌週動画の編集開始

日曜
 ├── YouTube Shorts: 1本公開
 ├── リサーチ部署: 翌週ネタの先行調査
 └── 予備日（遅れた制作物の仕上げ）
```

### 月間サイクル

```
月初（1〜3日）:
 ・先月KPIレビュー（COO・各部署リーダー）
 ・今月コンテンツカレンダー最終確認
 ・リサーチ部署: 競合動向月次レポート提出

月中（15日前後）:
 ・進捗レビュー（COO）
 ・必要であれば月後半のコンテンツ入れ替え

月末（28〜31日）:
 ・月間KPI集計・レポート作成
 ・翌月コンテンツ企画の確定
 ・研究所レター: 月次「まとめ」号配信
```

### 祝日・年末年始の対応

```
・コンテンツはすべて「事前制作・予約投稿」で運用
・祝日前週までに制作完了し、ツールで予約設定
・年末年始（12/29〜1/3）は「総集編・ベスト記事まとめ」で対応
・緊急ネタ（大きな試合・ニュース）のみ当日対応可
```
