## 2. カテゴリー設計

### 新カテゴリー名

**「プレーコンサルティング」**

なぜこの名前か:
- 「コンサルティング」= ビジネスでは当たり前の概念をサッカーに持ち込む
- 「分析」より「コンサルティング」の方が「継続的なサポート」の意味が強い
- 経営者がコンサルを使うように、選手がプレーコンサルを使う時代を作る

### カテゴリーの定義（LA FABRICAが作る）

```
プレーコンサルティングとは：

「選手個人のプレーデータを分析し、
 強み・弱みを明確にした上で、
 今この選手が着手すべきことと
 着手すべきでないことを設計し、
 成長の方向性を示す専門サービス」

── LA FABRICA, 2026
```

### アナロジー（認知形成に使う）

| 既存の当たり前 | サッカーでの当たり前（作る） |
|-------------|--------------------------|
| 経営者がコンサルタントを使う | 選手がプレーコンサルタントを使う |
| 病院で定期健診を受ける | 定期的にプレー分析を受ける |
| スポーツジムでパーソナルトレーナー | サッカーで個人分析コーチ |
| 受験生が塾で個別指導を受ける | 選手がIDP分析を受ける |

## 3. 認知形成の3ステップ

### Step 1：「練習だけでは上手くならない」という問題提起

**目的**: 現在の常識（練習＝上達）に疑問を持たせる

```
コンテンツの方向性:
・「練習しても上手くならない選手が増えている理由」
・「なぜ日本の育成は世界に負けているのか」
・「がんばりを量で測る文化の限界」
・「コーチに言われたことをやるだけでは上手くなれない理由」

感情：「え、練習だけじゃダメなの？」という違和感
→ 次のステップへの好奇心を作る
```

### Step 2：「自分を知ることが最初の一歩」という新常識の提示

**目的**: 「分析が先」という新しい行動順序を教える

```
コンテンツの方向性:
・「上手くなる選手が最初にやること」
・「自分の本当の弱点は自分では気づけない理由」
・「勘と感覚で練習している選手に伝えたいこと」
・「世界のトップ選手が個人分析を受け続ける理由」

感情：「自分も分析してみたい」という欲求
→ IDPへの自然な流れ
```

### Step 3：「LA FABRICAを使うのが当たり前」という行動の定着

**目的**: IDP分析を受けることを「合理的な選択」として定着させる

```
コンテンツの方向性:
・IDP参加者の成長ストーリー（Before/After）
・「分析を受けた選手が半年でどう変わったか」
・「セレクションに合格した選手が事前にやっていたこと」
・「IDP分析を受けた選手と受けなかった選手の差」

感情：「やらないと損だ」という確信
→ 申込行動
```

## 4. 先行者利益を取り切るための5つの打ち手

### 打ち手1：「プレーコンサルティング」という言葉を大量に撒く

YouTubeの動画タイトル・メディア記事・メルマガで
「プレーコンサルティング」「個人分析」という言葉を使い続ける。

LA FABRICAがこの言葉を使い始め、
競合がこの言葉を使い始めた時にはすでにLA FABRICAが定着している状態を作る。

```
具体的な行動:
・毎動画で「プレーコンサルティング」という言葉を使う
・「プレーコンサルティングとは何か」という記事を書く
・メルマガで定義を繰り返す
・SEOで「プレーコンサルティング サッカー」を独占する
```

### 打ち手2：酒本先生を「プレーコンサルティングの第一人者」として権威化

```
具体的な行動:
・YouTube自己紹介を「日本初のサッカープレーコンサルタント、酒本です」に統一
・メディアプロフィールを「プレーコンサルタント」で統一
・「プレーコンサルティングとは（酒本の定義）」という動画を作る
・他のインフルエンサー・指導者との対談でこの概念を広める
```

### 打ち手3：分析事例を圧倒的に蓄積・公開する

競合が「分析します」と言い始めた時、LA FABRICAにはすでに
100件・200件の分析実績がある状態を作る。

```
具体的な行動:
・IDP分析のBefore/Afterを毎月コンテンツ化
・「○○人を分析してわかったこと」系の動画を定期投稿
・「分析事例集」をメディアで公開（匿名）
・累計分析人数をチャンネルで公開し続ける
```

### 打ち手4：「プレーコンサルティングなしで上達しようとすること」をタブー化

「分析を受けずに練習し続けることは非効率だ」という認識を作る。

```
コンテンツの切り口:
・「あなたは間違った練習を何年続けてきたか」
・「分析なしで上達できる選手は全体の○%だけ」
・「セレクションに落ち続ける選手に共通する1つの盲点」
→ 「分析を受けないことがリスク」という認識を作る
```

### 打ち手5：価格を「投資」として認識させる

```
現在の認識: IDP = ¥5,000〜50,000（高い）
作りたい認識: IDP = 方向性を間違えた練習に費やす時間・お金に比べたら圧倒的に安い

コンテンツの切り口:
・「間違った練習を3年続けるコスト」（時間・スクール費用・機会損失）
・「正しい方向性で1年練習した選手」vs「闇雲に3年練習した選手」
・「セレクションに落ち続けるコスト」を可視化
```

## 7. 競合参入への対応

競合が「個人分析サービス」を始めた時、LA FABRICAは以下の資産で圧倒する:

| 資産 | 内容 | 競合が追いつくのに必要な時間 |
|-----|------|--------------------------|
| 分析事例数 | 累計○○人の分析実績 | 1〜2年 |
| コンテンツ資産 | YouTube○本・記事○本 | 1〜2年 |
| 研究所レター読者 | ○○人との直接接点 | 1〜2年 |
| 酒本先生の認知 | 第一想起の確立 | 不可能（個人ブランド） |
| IDPフレームワーク | 独自の分析手法 | 模倣困難 |

**結論**: 今すぐ動いた量と質が、そのまま参入障壁になる。
