## 🔄 プロセスの見える化

### 記事制作プロセス

```
リサーチ → 仮説検証 → 執筆 → レビュー → 公開
  ↓                              ↓
プロセス公開              読者フィードバック
（段階的に実施）           (Discussion)
```

### 各段階で見せる情報

- **リサーチ段階**: 「今月このテーマを扱う」という予告
- **仮説検証**: 分析中の発見やふり返り
- **執筆後**: 編集プロセスの裏側（なぜこの表現にしたか等）
- **公開後**: 反応・フィードバックの統合
