# LA-FABRICA IDP (Individual Development Program)

## 👤 事業概要

プレイヤーの能力を科学的に分析し、カスタマイズされた成長パスを提案するサービス

### 2つのサービス

#### 1️⃣ **分析サービス (Analysis)**
- 強み・弱みの科学的分析
- パフォーマンスデータの可視化
- 個別フィードバックレポート

#### 2️⃣ **成長設計サービス (Growth Design)**
- カスタマイズされた3ヶ月成長プラン
- 段階的なマイルストーン設定
- 定期的なレビューと調整

## 🔄 プロセスの見える化

### フレームワーク開発プロセス

```
指標候補の収集 → 優先順位付け → 実装 → パイロットテスト → 改善
                                      ↓
                          チーム内で学んだ教訓
                          ↓
                        公開（Discussionsで共有）
```

### 各段階で見せる情報

**✅ 見せる**:
- なぜこの指標を選んだのか
- テストで分かったこと
- 改善前後での違い

**🔒 見せない**:
- アルゴリズムの詳細実装
- スコアリング式の正確な計算式
- 個別プレイヤーの詳細データ

## 📋 パイロットテスト計画

### 参加者（予定）
- 異なるポジション: 5名
- 年代: U-15～U-20
- フィードバック能力: 積極的に意見をくれる人材

### テスト項目
- [ ] 分析レポートの理解しやすさ
- [ ] 提案された改善案の実現可能性
- [ ] フレームワークの改善提案

### 学んだ教訓の共有方法
- 月次レポート形式で、Discussionsで公開
- 匿名化された参加者の感想を共有

## 🎯 成功指標

| 指標 | 目標値 |
|-----|--------|
| 分析指標の有効性 | r > 0.7の相関を持つ |

| ベータユーザー数 | 10～20名 |
| 継続利用率 | 3ヶ月後に80%以上が継続 |
