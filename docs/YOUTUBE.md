# LA-FABRICA YouTube コンテンツ戦略

> **目的**: Youtubeをメインのオーガニック獲得チャネルとして機能させ、IDP・IDCへの申し込みを促進する

---

## 1. リサーチ

### 1-1. ターゲット視聴者

| セグメント | 特徴 | 主なニーズ |
|-----------|------|-----------|
| **主ターゲット** U-15〜U-20選手 | 上を目指している / 親がYoutubeを一緒に見る | 「自分は何が足りないのか」「どう練習すればいいか」 |
| **副ターゲット** 保護者 | 子どもの成長を真剣に考えている | 「信頼できるプログラムに投資したい」 |
| **拡散ターゲット** コーチ・指導者 | 選手育成の手法に関心 | 「新しい育成メソッドを知りたい」 |

### 1-2. 競合・参考チャンネル分析

| カテゴリ | 参考チャンネル例 | LA-FABRICAとの差別化ポイント |
|---------|----------------|--------------------------|
| 技術系サッカーYoutube | ドリブル塾・技術解説系 | 「技術単体」ではなく「個人分析に基づく成長設計」 |
| スポーツビジネス系 | サッカービジネス解説系 | 「構築過程をリアルタイムで見せる」プロセスエコノミー |
| 選手育成・アカデミー系 | クラブ広報動画 | 科学的分析 + 個別最適化の証拠を見せる |

### 1-3. 検索需要の高いキーワード（想定）

```
・サッカー 上手くなる方法 / 中学生 / 高校生
・サッカー 個人分析 / 弱点 / 改善
・サッカー ポジション別 練習方法
・サッカー キャンプ / 合宿
・サッカー スカウト / セレクション
```

### 1-4. 動画フォーマット別の特性

| フォーマット | 拡散力 | 転換率 | LA-FABRICA向きの用途 |
|------------|-------|--------|-------------------|
| Shorts（60秒以内） | 高 | 低 | 認知拡大・テクニック集 |
| 解説・分析動画（8〜15分） | 中 | 高 | IDP/IDCの価値説明 |
| ドキュメンタリー・密着動画（15〜30分） | 中 | 最高 | プロセスエコノミーの体現 |
| ライブ配信 | 低 | 高 | Q&A・コミュニティ形成 |

## 2. 企画

### 2-1. コンテンツの4本柱

```
┌─────────────────────────────────────────────┐
│  Pillar 1: 選手育成の「なぜ」を教える          │
│  → 視聴者の課題意識を作る                      │
├─────────────────────────────────────────────┤
│  Pillar 2: LA-FABRICAのプロセスを見せる        │
│  → IDP/IDC構築の舞台裏（信頼を作る）           │
├─────────────────────────────────────────────┤
│  Pillar 3: 参加者の成長ストーリー              │
│  → Before/After で効果を証明する              │
├─────────────────────────────────────────────┤
│  Pillar 4: サッカーの深い分析・戦術            │
│  → メディアとしての権威性を確立する             │
└─────────────────────────────────────────────┘
```

### 2-2. シリーズ企画

#### シリーズA: 「あなたのサッカーを分解する」（Pillar 1）
- **コンセプト**: IDP分析の考え方を使って、ポジション・スキル別の弱点と改善法を解説
- **形式**: 解説動画 10〜15分
- **投稿頻度**: 月2本
- **例タイトル**:
  - 「なぜあなたのパスは弱いのか？3つの原因と即効トレーニング」
  - 「センターバックが犯す最も多いポジショニングミス」
  - 「中学生サッカー選手が伸び悩む本当の理由を科学的に分析した」

#### シリーズB: 「LA-FABRICAの作り方」（Pillar 2）
- **コンセプト**: IDP・IDCの設計・失敗・改善過程をドキュメンタリー形式で公開
- **形式**: Vlog / ドキュメンタリー 15〜20分
- **投稿頻度**: 月1本
- **例タイトル**:
  - 「ゼロからサッカーのIDP分析サービスを作る #1」
  - 「初めてのキャンプ設計で失敗したこと（正直に話します）」
  - 「5人の選手を分析して気づいた『育成の盲点』」

#### シリーズC: 「選手の3ヶ月」（Pillar 3）
- **コンセプト**: IDC参加者・IDP利用者の成長を密着記録（本人同意のもと）
- **形式**: ドキュメンタリー 20〜30分
- **投稿頻度**: キャンプ後に1本（月1本ペース）
- **例タイトル**:
  - 「弱点を分析されてキャンプに参加した17歳の3日間」
  - 「ドリブルが課題だった選手が3ヶ月でどう変わったか」

#### シリーズD: 「試合・戦術分析」（Pillar 4）
- **コンセプト**: 注目試合・選手のプレーを分析。メディアとしての専門性を示す
- **形式**: 解説動画 10〜15分
- **投稿頻度**: 月1〜2本
- **例タイトル**:
  - 「なぜ久保建英はあのポジションで輝くのか」
  - 「2026年W杯で流行した戦術を高校生でも実践できる形に落とし込む」

#### Shorts戦略（全シリーズ共通）
- 各長尺動画から切り出し
- 「60秒サッカー分析」「練習ドリル1本紹介」
- 週2〜3本投稿

## 3. 台本

### 3-1. 台本テンプレート（解説・分析動画）

```
【フック】0〜30秒
  - 視聴者の共感を引く問い or 衝撃の事実
  - 「この動画で何が得られるか」を明示
  例: 「あなたが練習してもパスが上手くならない理由、
       それは技術の問題ではないかもしれません。
       今日はIDP分析から見えてきた『本当の原因』を話します。」

【自己紹介・信頼性】30秒〜1分
  - LA-FABRICA / kentoの簡単な紹介
  - なぜこのテーマを扱えるのか（根拠）

【本論1: 問題提起】1〜4分
  - 視聴者が感じている課題を具体化する
  - データや事例で「あるある」を作る

【本論2: 原因分析】4〜8分
  - IDP分析の考え方で原因を分解
  - 図・アニメーション・映像を活用

【本論3: 解決策】8〜12分
  - 具体的な改善アプローチ
  - 「自分でできること」と「専門サポートが必要なこと」を分ける

【CTA（行動喚起）】最後1〜2分
  ★ → 4章参照
```

### 3-2. 台本テンプレート（ドキュメンタリー/プロセス動画）

```
【オープニング】0〜1分
  - その回で何が起こったかの「結果予告」
  例: 「今日は初めてのキャンプを開催します。
       でも正直に言うと、設計に大きなミスがありました。」

【背景・文脈】1〜3分
  - 前回から今回への流れ
  - 視聴者に「一緒に作っている」感を持たせる

【メインドキュメント】3〜18分
  - リアルな出来事（成功・失敗・悩み）を記録
  - 「なぜその判断をしたか」を必ず語る

【学んだこと・次のステップ】18〜20分
  - 教訓を整理して視聴者に価値提供
  - 次回予告で続きを見たくさせる

【CTA】最後1分
  ★ → 4章参照
```

### 3-3. 台本例:「シリーズA 第1弾」

---

**タイトル案**: 「なぜあなたは練習しても上手くならないのか？IDP分析が教える3つの盲点」

ボールを受ける場所が悪ければ、試合でドリブルを使えません。」

**[盲点2〜3: 省略]**

**[CTA 13:00〜14:00]**
→ 次章参照

## 4. YouTubeからLA-FABRICAのサービスへの誘導

### 4-1. ファネル設計

```
[Youtube 視聴]
      │
      │ 興味・共感
      ▼
[チャンネル登録 / Shorts → 長尺視聴]
      │
      │ 信頼感の醸成（シリーズを通じて）
      ▼
[概要欄 / コメント欄のリンクからLPへ]
      │
      ▼
[IDP 無料相談 または IDC 説明会に申込]
      │
      ▼
[IDP 分析サービス ¥5,000〜 / IDC参加 ¥20,000〜]
```

### 4-2. 動画内CTA（Call to Action）設計

#### 基本CTAスクリプト（全動画共通・最後1〜2分）

```
「今日の話で、自分の課題が気になった人へ。

LA-FABRICAではIDP分析として、
あなたのプレーを科学的に分析して、
"あなたが今伸ばすべきポイント"を明確にするサービスをやっています。

分析レポートを受け取ると、
今日話したような『なんとなく練習している』状態から抜け出せます。

詳細は概要欄のリンクから確認してみてください。
無料相談も受け付けているので、まずは気軽にどうぞ。

チャンネル登録もお願いします。
次回は[次の動画テーマ]について話します。」
```

#### 動画タイプ別CTAの強弱

| 動画タイプ | CTA強度 | 理由 |
|-----------|--------|------|
| 技術解説・分析（Pillar 1） | 中〜強 | 課題意識が高まっているタイミング |
| プロセス・ドキュメント（Pillar 2） | 弱〜中 | まず信頼を積む段階。売り込みNG |
| 成長ストーリー（Pillar 3） | 強 | 効果の証拠を見た後の最高のタイミング |
| 戦術分析（Pillar 4） | 弱 | 認知・権威性が目的 |
