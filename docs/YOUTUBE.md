# LA-FABRICA YouTube コンテンツ戦略

> **チャンネル名**: サッカー選手育成工場「ラ・ファブリカ」
> **登録メール**: info@ladoce.jp
> **コンセプト**: 「酒本先生」が育成の本当のことを直接語る — 脱税理士スガワラくん型の教育チャンネル

## チャンネル名について

**サッカー選手育成工場「ラ・ファブリカ」**

- `LA FÁBRICA` = スペイン語で「工場」→ ブランド名の意味がそのままチャンネル名になる
- 「工場」= 科学的・体系的・再現性がある育成のイメージ
- 「選手育成工場」= IDP・IDCというサービスの本質を一言で表す
- 覚えやすく、Shortsでバズった時に「ラ・ファブリカって何？」と検索される

## 1. チャンネルの基本設計

### なぜスガワラくん型か

| スガワラくん | 酒本先生（LA-FABRICA） |
|------------|----------------------|
| 「税金の本当のことを教えます」 | 「サッカー育成の本当のことを教えます」 |
| 税法・データを根拠に語る | IDP分析・データを根拠に語る |
| 「実は知られてない節税法」 | 「実は知られてない選手が伸びない理由」 |
| 視聴者の味方（税務署側でなく納税者側） | 視聴者の味方（クラブ側でなく選手・保護者側） |
| 専門家だが忖度しない | 分析家だが感情論に流されない |

**核心**: 他のサッカーYoutuberが「経験談」で語るのに対し、酒本先生は「**分析結果**」で語る。これがチャンネルの唯一の差別化。

## 2. 酒本先生のキャラクター設計

### ポジション定義

```
「サッカー育成アナリスト」

選手を感情論でなく、データと分析で見る人間。
正直に言う。でも選手の味方。
```

### キャラクターの3軸

#### 軸1: 「正直に言う人」
- 一般的な指導者が言いにくいことをズバッと言う
- 根拠があるから言える（IDP分析という武器）
- 例: 「そのトレーニング、あなたには合っていません。正直に言います。」

#### 軸2: 「データで語る人」
- 「僕が見てきた選手の中で〇〇%が〜」
- 「分析してみたら、こういう結果が出ました」
- 感情論・精神論に流れない
- 例: 「根性でどうにかなる、と言う指導者がいますが、分析してみると実際は〇〇が原因です。」

#### 軸3: 「選手・保護者の味方」
- クラブや指導者の言いなりにならなくていい、という立場
- 「あなたが正しい選択をするために必要な情報を渡す」スタンス
- 例: 「コーチに言われた練習をそのままやり続けていると、こういうリスクがあります。」

### 口癖・フレーズ（キャラを固定する言葉）

| フレーズ | 使うタイミング |
|---------|--------------|
| 「正直に言います」 | 少し辛口なことを言う前 |
| 「分析してみると〇〇でした」 | データや事例を出す時 |
| 「これ、意外と知られてないんですけど」 | 反直感的な内容を出す前 |
| 「感情論じゃなくて、データで話します」 | 冒頭の自己紹介・信頼性付与 |
| 「〇〇な選手は、一回聞いてください」 | CTA前の対象者の絞り込み |

### やらないこと（キャラを守るために）

- 根拠のない精神論・根性論
- クラブ・指導者を名指しで批判
- 「絶対上手くなる」系の誇大表現
- 視聴者に媚びるコメント返し

## 3. タイトル法則（スガワラくん型）

### 法則一覧

#### 法則1: 断言型 — 「〇〇は間違いです」
視聴者の常識を壊す。反射的にクリックさせる。

```
例:
・「その練習メニュー、間違っています（分析して分かったこと）」
・「毎日練習すれば上手くなる、は半分嘘です」
・「コーチに怒られたら成長できる、は嘘です」
```

#### 法則2: 損失回避型 — 「知らないと〇〇になります」
人は「損したくない」という感情に強く反応する。

```
例:
・「これを知らないまま練習すると、3年後に後悔します」
・「セレクションで落ちる選手がやりがちな〇〇」
・「伸びない時期に続けてはいけないトレーニングがあります」
```

#### 法則3: 暴露型 — 「本当のことを話します」
専門家が「内側の話」をしてくれる感。信頼感と希少性が上がる。

```
例:
・「なぜあの選手は伸びたのか、正直に話します」
・「サッカーの育成現場で起きていることを分析してみた」
・「指導者が言わない、選手が伸び悩む本当の理由」
```

#### 法則4: 数字型 — 「〇〇な選手の△△%が〜」
具体的な数字で説得力を作る。

```
例:
・「伸び悩む選手の8割が、同じミスをしています」
・「3つの指標を見れば、あなたの課題がわかります」
・「6ヶ月で成長した選手に共通する、たった1つのこと」
```

#### 法則5: ターゲット直撃型 — 「〇〇な人へ」
視聴者に「自分への動画だ」と思わせる。CTR（クリック率）が上がる。

```
例:
・「練習しているのに試合で活躍できない選手へ」
・「子どものサッカーで悩んでいる保護者の方へ」
・「セレクション前の選手に、正直に言います」
```

### タイトル生成の公式

```
[ターゲット絞り込み] + [損失 or 発見] + [信頼性の根拠（任意）]

例:
「練習しても伸びない選手へ」 ＋「その原因、実は〇〇でした」 ＋「（分析して分かったこと）」
→「練習しても伸びない選手へ。その原因、分析して分かりました」

「保護者の方へ」 ＋「やってはいけないサポートがあります」 ＋「正直に言います」
→「子どものサッカー。やってはいけない親のサポート3選（正直に言います）」
```

### タイトルバンク（すぐ使えるもの）

```
■ 育成・成長系
・「なぜあなたは練習しても上手くならないのか。正直に言います」
・「サッカーが上手くなりたいなら、まず〇〇をやめてください」
・「伸び悩んでいる選手に共通する、たった1つの問題」
・「上手くなる選手と伸び悩む選手、分析してみたら差は〇〇でした」

■ セレクション・評価系
・「セレクションで落ちる選手に、正直に言います」
・「スカウトが見ている本当のポイントを教えます」
・「評価されない選手が気づいていない〇〇」

■ 保護者向け
・「子どものサッカーで、親がやってはいけないこと（分析して分かりました）」
・「お子さんが伸びない理由、保護者の方に正直に話します」

■ ポジション・技術系
・「ドリブルが上手くならない本当の理由（技術の問題じゃありません）」
・「センターバックが犯す、最もコストの高いミスとは」
```

## 4. 台本フォーマット（先生が直接語る構成）

### 基本構造（スガワラくん型）

```
① フック        0:00〜0:30  → 「あ、自分のことだ」と思わせる
② 結論先出し    0:30〜1:00  → 今日言いたいことを先に言う
③ 根拠・信頼性  1:00〜2:00  → なぜ自分がそれを言えるのか
④ 詳細解説      2:00〜11:00 → 具体的に教える（本編）
⑤ まとめ        11:00〜12:00→ 一言で整理
⑥ CTA           12:00〜13:00→ 自然な誘導
```

### 各パートの書き方

#### ① フック（0:00〜0:30）
「視聴者の痛みを代弁する」のが鉄則。質問か断言で始める。

```
パターンA（質問）:
「毎日練習しているのに、試合で活躍できない。
そういう選手、周りにいませんか？ あるいは自分がそうですか？
今日はその原因を、分析してわかったことをもとに話します。」

パターンB（断言）:
「正直に言います。
その練習メニュー、あなたには合っていない可能性があります。」

パターンC（数字・事実）:
「僕がこれまで分析してきた選手の中で、
伸び悩んでいる選手の8割が、同じ問題を抱えていました。
今日はその話をします。」
```

#### ② 結論先出し（0:30〜1:00）
スガワラくん型の最大の特徴。最後まで見なくても価値がわかる = 最後まで見たくなる。

```
「今日言いたいことを先に言います。
伸び悩んでいる選手の多くは、練習量の問題ではなく、
『自分の課題を正確に把握できていない』という問題を抱えています。
詳しく説明します。」
```

#### ③ 根拠・信頼性（1:00〜2:00）
「なぜ自分がこれを言えるのか」を毎回きちんと語る。積み重ねるとチャンネルの資産になる。

```
「LA-FABRICAというサッカー育成の事業をやっています。
IDP、Individual Development Program といって、
選手のプレーを分析して、個別の成長プランを作るサービスです。

これまで[人数]人の選手を見てきて、
今日話す問題は、本当によく見るパターンです。」
```

#### ④ 詳細解説（2:00〜11:00）
「1テーマ = 1動画」が基本。3つのポイントに分けると構成しやすい。

```
構成例（3ポイント型）:

「問題は3つあります。順番に話します。

1つ目が〇〇です。
[具体的な例・映像・図で説明]
[よくある誤解を先に出して、正解を言う]

2つ目が〇〇です。
[同上]

3つ目が〇〇です。
[同上]」
```

#### ⑤ まとめ（11:00〜12:00）
一言で整理。視聴者が「シェアしたくなる」ような言い切りで終わる。

```
「まとめます。
伸び悩む選手に共通するのは、[一言で言えること] です。
練習量の問題ではなく、[核心] の問題です。
これを知っているだけで、アプローチが変わります。」
```

## 5. サービス誘導の自然なフレーズ

### 設計思想

スガワラくん型のCTAの特徴は「押し売りしない」こと。
視聴者の状態を「絞り込んで」から、解決策として自分のサービスを提示する。

```
❌ 「IDPに申し込んでください！」（直接的すぎる）
⭕ 「こういう人は一回話を聞いてください」（限定・呼びかけ）
```

### CTAフレーズバンク

#### パターン1: 「こういう人向けに〜をやっています」（限定型）

```
「今日の話で、自分の課題が何なのかわからない、という人向けに、
IDP分析というサービスをやっています。
あなたのプレーを分析して、今伸ばすべきポイントを明確にします。
概要欄にリンクあるので、気になった人は見てみてください。」
```

#### パターン2: 「なんとなく〇〇な人は〜」（共感型）

```
「なんとなく課題はわかってるけど、何から始めればいいかわからない、
という状態の選手、多いと思います。
そういう選手に向けて、無料相談を受け付けています。
話を聞くだけでも全然いいので、気軽にどうぞ。」
```

#### パターン3: 「ちなみに僕がよく相談されるのは〜」（会話型）
動画の流れの中で自然にサービスに触れる。CTAより前に入れる。

```
「ちなみに僕がよく相談されるのは、
『練習は頑張っているのに何が足りないのかわからない』というケースです。
そういう選手はIDP分析を受けると、かなり明確になります。」
```

#### パターン4: 「正直、自分一人でやるのは難しい」（共感 → 解決策型）

```
「今日話した『自分の本当の課題を把握する』というのは、
正直、自分一人でやるのはかなり難しいです。
だから僕たちが外から分析する、ということをやっています。
興味ある方は概要欄から。」
```

### CTA配置の設計（タイミング）

```
[動画本編]
      │
      ├─── まとめの手前で「ちなみに〜」型を1回（自然な言及）
      │
      └─── エンディングで「こういう人は〜」型を1回（明示的なCTA）
```

### 動画タイプ別CTAの強弱

| 動画タイプ | CTA強度 | 推奨フレーズ |
|-----------|--------|------------|
| 育成・課題解説（メイン） | 中〜強 | パターン1 + パターン4 |
| プロセス・舞台裏ドキュメント | 弱 | パターン3のみ（さりげなく） |
| 参加者の成長ストーリー | 強 | パターン2（感情が高まっているタイミング） |
| 戦術・試合分析 | 弱〜なし | チャンネル登録のみ促す |

## 6. 企画（コンテンツシリーズ）

### シリーズ設計

| シリーズ | コンセプト | タイトル法則 | CTA |
|---------|-----------|------------|-----|
| **A: 育成の本当のこと** | 酒本先生が正直に語る | 断言型・損失回避型 | 強 |
| **B: LA-FABRICAの作り方** | 構築過程のドキュメント | 暴露型 | 弱 |
| **C: 選手の3ヶ月** | 参加者Before/After密着 | ターゲット直撃型 | 強 |
| **D: 戦術・試合分析** | 専門性・権威性の確立 | 数字型 | なし〜弱 |

### シリーズA: 「育成の本当のこと」（主力）

メインシリーズ。酒本先生キャラを最も体現する。

- **投稿頻度**: 月2本（週1本が理想）
- **尺**: 10〜14分
- **形式**: 顔出し一人喋り + テロップ + 図解

**タイトル例**:
```
・「なぜ練習しても上手くならないのか。正直に言います」
・「伸び悩む選手の8割が知らない、たった1つの問題」
・「その練習メニュー、あなたには合っていません（分析して分かったこと）」
・「セレクションで落ちる選手に正直に言います」
・「ドリブルが上手くならない本当の理由（技術の話じゃありません）」
・「保護者の方へ。子どものサッカーでやってはいけないこと3選」
```

### シリーズB: 「LA-FABRICAの作り方」

プロセスエコノミーを体現。視聴者を「一緒に作っている」感覚にさせる。

- **投稿頻度**: 月1本
- **尺**: 15〜20分
- **形式**: Vlog / 語り

**タイトル例**:
```
・「ゼロからサッカー分析サービスを作っています #1」
・「初めてのキャンプ設計で失敗したこと（正直に話します）」
・「5人の選手を分析して気づいた『育成の盲点』」
```

### シリーズC: 「選手の3ヶ月」

転換率最高シリーズ。IDC参加者の成長密着。

- **投稿頻度**: キャンプ後に1本
- **尺**: 20〜30分
- **形式**: ドキュメンタリー

**タイトル例**:
```
・「分析結果を持ってキャンプに参加した17歳の3日間」
・「ドリブルが課題だった選手が3ヶ月でどう変わったか」
```

### Shorts戦略

- シリーズAの長尺から切り出す（制作コストゼロ）
- 「1つの事実だけを60秒で言い切る」形式
- タイトルも同様の法則で

```
例:
・「伸び悩む選手に共通する1つのこと」（60秒）
・「練習前にやるべきことがあります」（45秒）
```
