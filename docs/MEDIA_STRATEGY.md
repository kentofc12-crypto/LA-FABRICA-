# media.lafabrica.jp コンテンツ戦略

> **目的**: メディアを「IDP/IDCサービスの潜在顧客を集め、研究所レターに登録させ、購買に転換する」マシンにする

---

## 1. 現状把握

### サイト構造（確認済み）

```
ナビゲーション:
  分析・戦術 / エビデンス / 対談 / サービス紹介

ヘッダーCTA（赤ボタン）:
  「LA FÁBRICA研究所レター登録」← 既に存在

現在の記事:
  ・カラバオ杯決勝でアーセナルを沈黙させたシティ流[4-2-4]
  ・バルサ攻撃グループ戦術「WG&SBローテーション前進」
  ・なぜ世界最高のドリブラーはフットサルから生まれるのか
  → プロサッカーの戦術分析が中心
```

### 現状の問題

| 問題 | 内容 |
|------|------|
| コンテンツと購買層のズレ | 現記事はサッカーファン・指導者向け。IDP/IDCの購買層（U-15〜20選手・保護者）に刺さっていない |
| 研究所レターの登録動機が弱い | 「分析や最新記事をお届け」では登録理由が薄い |
| 記事からサービスへの動線がない | 読んで終わり。次のアクションが設計されていない |

## 3. コンテンツ設計（2層構造）

### 層1: 既存コンテンツ（権威性の確立）

現在の戦術分析・エビデンス記事はそのまま継続。
「LA FABRICAは本物だ」という信頼を作る資産。

**役割**: 読者の質を高める。コーチ・指導者・意識の高い保護者を集める。

### 層2: 育成・選手向けコンテンツ（購買層への直接訴求）【新設】

**ターゲット**: U-15〜20選手 + その保護者

現在のカテゴリに加え、以下の方向性で記事を追加していく。

## 4. 記事カテゴリと方向性

### 既存カテゴリの活用

| カテゴリ | 現在の内容 | 追加すべき方向性 |
|---------|-----------|---------------|
| **分析・戦術** | プロの戦術分析 | 「この戦術を選手が実践するには」の視点を加える |
| **エビデンス** | 科学的根拠 | 育成・トレーニング科学の記事を追加 |
| **対談** | （現状不明） | IDP/IDC参加者インタビューを追加 |
| **サービス紹介** | サービスLP | そのまま活用 |

### 新設すべき記事の方向性

既存カテゴリの中に混ぜ込む形で、以下テーマの記事を積み上げる。

#### テーマA: 「選手の伸び悩み」に答える記事
購買意向が最も高い層に刺さる。IDP分析への自然な橋渡し。

```
例タイトル:
・「なぜ練習しても上手くならないのか。分析してわかった3つの原因」
・「伸び悩む選手に共通する、たった1つの問題」
・「ドリブルが上手くならない本当の理由（技術の問題ではありません）」
・「セレクションで落ちる選手に正直に言います」
```

#### テーマB: 「プロの技術・戦術を選手目線で解説」する記事
既存の戦術記事と橋渡しするコンテンツ。

```
例タイトル:
・「バルサのWG&SBローテーションを、高校生が実践するには何が必要か」
・「世界最高のドリブラーのプレーから学べること。あなたの練習に活かす方法」
・「シティの守備組織から学ぶ、ポジショニングの本質」
```

#### テーマC: 「保護者向け」記事
保護者は意思決定者。IDP/IDCの購買者になる。

```
例タイトル:
・「子どものサッカー。親がやってはいけないサポート3選」
・「育成年代のコーチ選びで見るべき、たった1つのポイント」
・「月いくら投資すれば、サッカー選手として成長できるのか」
```

#### テーマD: 「LA FABRICAの現場から」記事（プロセスエコノミー）
```
例タイトル:
・「IDP分析フレームワークをゼロから設計した話」
・「初めてのキャンプで失敗したこと、正直に書きます」
・「分析を受けた選手が3ヶ月でどう変わったか」
```

## 5. 研究所レター（メルマガ）設計

### 登録動機の強化

現状の登録理由「分析や最新記事をお届け」は弱い。
登録することで「明確に得られるもの」を前面に出す。

#### 登録フォームのコピー案

**現状**:
```
「LA FÁBRICAから、フットボールの分析や最新記事、
 セミナーやキャンプ情報などをお届けします。」
```

**改善案A（選手・保護者向け）**:
```
「LA FÁBRICA研究所レター」

サッカーで最高の自分になるために必要な知識を、
毎週メールでお届けします。

・伸び悩む選手が変わるための分析視点
・世界基準の育成メソッドを日本語で解説
・IDP分析・IDCキャンプの先行情報

登録無料。いつでも解除できます。
```

**改善案B（登録特典をつける）**:
```
「LA FÁBRICA研究所レター」

登録特典: 「あなたの課題カテゴリがわかる、
          セルフチェックシート（PDF）」を無料プレゼント

毎週、サッカーの本物の学びをお届けします。
```

### メルマガの配信設計

#### 登録直後（ステップメール）

| タイミング | 内容 | 目的 |
|-----------|------|------|
| 登録直後 | 「ようこそ。まずこれを読んでください」+ 人気記事3本 | 最初の価値提供 |
| 3日後 | 「選手が伸び悩む3つのパターン」（オリジナル記事） | 課題意識を作る |
| 7日後 | 「IDP分析とは何か」の説明 | サービス認知 |
| 14日後 | 「無料相談を受けてみませんか」 | IDP誘導 |
| 30日後 | 「IDCキャンプのご案内」 | IDC誘導 |

#### 定期配信（週1回）

```
構成:
1. 今週のピックアップ記事（メディアへの誘導）
2. 酒本先生からの一言（短い育成ヒント）
3. お知らせ（IDP/IDCの残枠・先行情報など）
```

#### メルマガのトーン

スガワラくん型と同じく「先生から直接届く手紙」感。
大量配信ではなく、「選ばれた人への情報」という希少感を作る。

```
件名の法則:
・「正直に言います。○○な選手は伸びません」
・「今週の分析：なぜ○○選手はあそこにいたのか」
・「あなたへ。○○について話したいことがあります」
```

## 6. 記事内の導線設計

### 導線の3段構造

```
段階1: 記事の途中（さりげない言及）
  ↓ 全記事に仕込む。売り込み感ゼロ。

段階2: 記事末のCTAボックス（研究所レター登録）
  ↓ 全記事に必ず設置。購買より先にメルマガ登録へ。

段階3: メルマガ内でIDP/IDCへ誘導
  ↓ 信頼を積んでから購買を促す。
```

### 記事途中の自然な言及（段階1）

```
本文の流れ例:
「...ポジショニングの課題は、自分では気づきにくい。
 第三者の視点で見てもらうことで、初めて見えてくることが多い。
 
 ちなみにLA-FABRICAのIDP分析では、こういった
 認知・判断の課題も含めて分析しています。
 詳しくは後述します。」
```

### 記事末のCTAボックス（段階2）

**全記事共通（メルマガ登録ファースト）**:

```
┌──────────────────────────────────────────┐
│                                          │
│  📬 LA FÁBRICA研究所レター               │
│                                          │
│  この記事のような「本物の学び」を、       │
│  毎週メールでお届けしています。           │
│                                          │
│  サッカーで最高の自分になるための知識を   │
│  蓄積したい方へ。登録無料。              │
│                                          │
│  [研究所レターを受け取る →]             │
│                                          │
└──────────────────────────────────────────┘
```

**育成・選手向け記事のみ追加するCTA（段階2.5）**:

```
┌──────────────────────────────────────────┐
│                                          │
│  🔍 自分の課題を正確に知りたい方へ        │
│                                          │
│  IDP分析では、あなたのプレーを            │
│  技術・戦術・身体・メンタルの4軸で分析。  │
│  「今伸ばすべきポイント」を明確にします。  │
│                                          │
│  まず無料相談から。[申し込む →]          │
│                                          │
└──────────────────────────────────────────┘
```

### CTAの優先順位

```
1st: 研究所レター登録（全記事・全読者）
2nd: IDP無料相談（育成・選手向け記事のみ）
3rd: IDCキャンプ案内（成長ストーリー記事のみ）
```

## 7. 記事フォーマット（酒本先生型）

### 共通ルール

- **タイトル**: 断言型・損失回避型・暴露型（YouTube戦略のタイトル法則と同じ）
- **リード文**: 結論を先に言う。「この記事でわかること」を3行以内で
- **本文**: 1テーマを深く。3つのポイントに分解
- **文体**: 「〜です/ます」調。媚びない。でも読者の味方

### 記事タイプ別構成

#### タイプA: 教育型（メイン）

```
タイトル
リード（200字・結論先出し）
H2: 一般論・よくある誤解（共感）
H2: 「実は違います」（反転）
H2: 根拠・データ・事例
H2: 選手にできること
まとめ（一言で言える結論）
CTAボックス（研究所レター）
```

#### タイプB: 戦術分析型（既存路線）

```
タイトル
リード（試合・選手の背景）
H2: 戦術の構造分析
H2: なぜそれが機能したのか
H2: 選手目線で学べること（育成への接続）
まとめ
CTAボックス（研究所レター）
```

#### タイプC: 成長ストーリー型（転換率最高）

```
タイトル
登場人物の紹介（Before）
IDP分析で何がわかったか
IDCで何をやったか
3ヶ月後の変化（After）
本人コメント
CTAボックス（研究所レター + IDP相談）
```

## 9. YouTubeとの関係（独立だが補完）

独立した資産として運用。コンテンツは別物を作る。

```
YouTube → メディア:
  動画の概要欄に「詳しくはメディアの記事で」と記載
  → 動画で興味を持った人が記事でより深く学ぶ

メディア → YouTube:
  記事の中に「この内容を動画で見たい方へ」と埋め込み
  → 検索で来た読者にYouTubeチャンネルを知ってもらう

共通のゴール:
  どちらも「研究所レター登録」に流す
  メルマガが中央のハブになる
```
